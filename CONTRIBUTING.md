# Contributing to VOLPAROSSA

VOLPAROSSA is an early-stage open-source project. Contributions should be small, reviewable, and accurately describe what is implemented versus proposed.

## Start here

Read the relevant repository README and documentation before proposing changes. For network-core contributions, consult the [core contributor guide](https://github.com/VOLPAROSSA/volparossa/blob/main/CONTRIBUTING.md) and its architecture, privacy model, and test requirements. Repository-specific guides take precedence over these defaults.

For general questions, use [central GitHub Discussions](https://github.com/VOLPAROSSA/volparossa/discussions). Use the appropriate repository's issues for reproducible bugs and specific feature proposals.

## Pull requests

- Explain the problem, change, safety implications and tests actually performed.
- Keep changes scoped, include tests for new behavior and document unresolved limitations.
- Do not claim successful tests, real-world security properties or supported releases without evidence.
- Preserve upstream licenses and provenance. Do not submit secrets or personal data.
- Submit changes through a pull request; repository-specific protections and review requirements apply.

## Security reports

Do not disclose vulnerabilities, exploitation steps, tokens, private logs or identifying data in public issues. Use the affected repository's **Security** tab and private vulnerability reporting where available. See the [core security policy](https://github.com/VOLPAROSSA/volparossa/blob/main/SECURITY.md) for project-wide principles.
