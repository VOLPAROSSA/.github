# VOLPAROSSA community resources

This repository hosts the [organization profile](profile/README.md) and default
community guidance for VOLPAROSSA's public repositories. Start with the
[core project](https://github.com/VOLPAROSSA/volparossa) to explore the network,
applications and source-bound development evidence.

- [Contributing](CONTRIBUTING.md): find a useful first task and prepare a reviewable change.
- [Code of conduct](CODE_OF_CONDUCT.md): participation and proportionate moderation.
- [Support and discussions](SUPPORT.md): find the right place for a question.
- [Security](SECURITY.md): report vulnerabilities privately.
- [Accessibility](ACCESSIBILITY.md): report barriers and improve access.

Repository-specific files take precedence over these defaults. GitHub does not
inherit a license from this repository: each project must retain its own license
and all applicable upstream notices. Original VOLPAROSSA code is GPL-3.0-only;
application integrations may contain differently licensed upstream components.

Maintain shared guidance here rather than copying it into every repository.
The core's detailed engineering rules, application-specific build instructions
and original evidence remain in their owning repositories.
